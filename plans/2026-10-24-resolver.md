## Design
1. New `job/resolver.py`. Scope table INSCOPE: yellowpages, superpages, dexknows, google, merchantcircle, hotfrog, n49, yellowbot, cybo. Anything else returns "out of scope" and is untouched.
2. Per-Directory plan = ordered queries. Search rules in code: (a) query ladder is one distinctive word (identity `search_words`, else derived from the name minus generic words), then phone digits, then the full name; per-Directory `skip_kinds` (superpages: phone, which 500s; yellowbot: phone and name, one word only). (b) n49 uses the existing `discover.own_search_box` which picks the location autocomplete suggestion; every URL search carries City, ST so the IP city is never used. (c) pagination only by following the pager anchor the page itself exposes (`next_page_link`), max 2 extra pages; the resolver never builds `?page=N`. (d) a listing is told from a search page by `permalink.is_permalink` (URL shape) AND a page tell on the text (`Results for`, `Showing 1-N of M`, `Top N Best`).
3. Card agreement before any follow: the card link must be on the Directory host, pass `listing.is_permalink` and `permalink.is_permalink`, and its text/aria/card agree with the business by name token or phone digits (reuses `listing._name_hit`). No agreeing card, no follow.
4. After the follow: read the page with the existing fetcher, final URL after redirects, `core.judge_listing` (name + NAP + city) on THAT page, shape and page tell. google: the `/maps/search/` URL must land on `/maps/place/` (one match) and `mapnap.judge_map` must agree. cybo: direct slug URL, NAP confirmed. Blocked (`core.classify`) stays blocked and reports the blocker; no CAPTCHA step, no login.
5. Wiring: `run.discover_live` on_complete runs `resolver.resolve_found_rows` with the live ChromeFetcher before `read_claim_pages`. For each SCC/NM in-scope cell that is found but whose URL fails the gate, it resolves and appends one `chrome-resolver` row (status found, listing URL, evidence from the listing page) to CE_ROWS. `judge.combine` dedup already prefers the passing URL. Misses add no row, so absent logic is unchanged. Env `CE_RESOLVER=0` turns it off. FAKE is never resolved.
6. Tests `tests/resolver_test.py` (CI): saved HTML fixtures, one search page and one listing page per in-scope Directory (scrubbed placeholder identity), stub fetcher with no network: picks the right link, ignores a decoy card (name mismatch), a listing result passes the gate, a category/search page never passes, blocked page stays blocked, no `page=` URL built, out-of-scope untouched, FAKE never resolved, no portal or Directory-write call in resolver.py. Plus category gate tests in `tests/permalink_test.py`.
7. Dry run `tests/resolver_dry_run.py`: read only, SCC only, in-scope only, run from this scratch clone, writes only to the workspace out dir. Reports per Directory resolved URL, NAP read, match against Edith's URL.
