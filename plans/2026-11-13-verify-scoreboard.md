# Plan: Verify Now per-stage scoreboard + step-trace capture (t_e49457af)

Cites lesson `docs/lessons/2026-11-13-age-is-not-death-ask-the-owner.md`: do not infer a state from a proxy (age); ask the owner of the fact. Here: each stage time is stamped by the actor that did the thing (bridge, send run, helper), never reconstructed afterwards from log lines or from portal columns that only exist for some stages.

Scope:
1. `job/verify_scoreboard.py`: `stamp(rid, stage, at=None, **meta)` (first write wins per stage, never raises, stage + meta allow-listed, never a code) into a per-request scratch file under `CE_LOGS/verify-stages/`; `finalize(rid, outcome)` appends ONE row to `CE_LOGS/verify-scoreboard.jsonl` (default `%LOCALAPPDATA%/citation-engine/logs`) and removes the scratch file (idempotent: a second finalize writes nothing). Fields: request_id, tenant, domain, channel, requested_at, bridge_pickup_at, agent_start_at, signed_in_at, send_clicked_at, code_sent_at, code_submitted_at, code_entered_at, verified_at, outcome, send_mode.
2. Stamp points: bridge `dispatch` (requested_at, bridge_pickup_at = portal claimed_at); send run (tenant, domain, send_mode, agent_start_at on launch / script browser open, signed_in_at, send_clicked_at, code_sent_at for script); helper `sent` (send_clicked_at, code_sent_at), `stage signed_in` (agent), `code` (code_submitted_at when consume returns it), `result` (code_entered_at). `finalize` runs inside `VerifyRpc.finish` after a successful RPC, so every close path (helper, send run, sweeper, fence refusal) is covered by one hook. verified_at is the finish time of a `verified` finish.
3. `python job/verify_scoreboard.py --summary [--file F]`: one table row per run, plus medians: click-to-send (requested -> code_sent), code-to-verified (code_submitted -> verified), pickup+start (requested -> agent_start) with a >90 s flag.
4. Trace capture: `verify_step.py trace --request-id X --action goto|click|fill|press --url U [--selector S]` (only while the request is `starting`, i.e. before the send; no value argument, so a typed secret or code has no path in; URL query/fragment stripped, selector capped). On a clean `sent` the trace is promoted to `CE_LOGS/verify-traces/promote/<domain>__<channel>__<rid>.json` (domain, channel, steps, request id) for a follow-up card to turn into a `send=script` entry. Prompt updated to tell the agent to call `trace` after each action and `stage --name signed_in`.
5. Click-to-send log line stays. No change to fence(), tenant lock, 3-sends cap, client click. No portal write beyond what the existing helper does.
6. Tests: `tests/verify_scoreboard_test.py` (CI) with a virtual wall clock; one mutation per stage timestamp run by `--mutations` (a copy of job/ with that stamp renamed, the test must fail). Dry run prints one sample row.
7. Measure the bridge poll: summary reports the pickup and pickup+start medians; the completion states what the first runs show (none yet = stated as such) and proposes the fix by the numbers.
No live send, no portal write, no deploy.
