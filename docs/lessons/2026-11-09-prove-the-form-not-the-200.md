# Lesson: prove the add form from the page HTML, not the status code

Six substitute candidates all answered a plain GET. Only one had an add form I could read: yplocal 403, nearspotusa a Cloudflare challenge, openlocaldirectory only a contact form, localcitation behind a login with spam links, uscompanieslist a data seller, dominion a claim form with no street address.
Rule: a row earns promotion only when the page HTML shows a free add path and the fields (street address and phone), the listing host equals the row domain, and it is not lead-gen. A 200 proves nothing. Check the queue and Catalog first: two "candidates" (listyourbusiness.us, getlistedusa.com) were already live rows.
Also: a missing queue row is not a missing Directory. n49 has no row because buildrows skips a found, NAP-correct, permalinked listing by design. Read the status before writing a fix.
