# 2026-10-28 — Batch 22 fixture proof is not account proof

- HTML attributes may encode query separators; unescape before extracting reCAPTCHA iframe keys, and test `k` as both first and subsequent parameter without touching full-page Cloudflare parking.
- A vault helper can choose the wrong same-URL browser tab. Focus the Playwright page and reject a changed URL before handoff, while leaving the helper's origin and visible-input checks intact. Credential-free fake-page tests prove the guard, not a live fill.
- A code typed into an email form is not a submitted code or server-confirmed account. Keep registration history, two solver calls and two prior wall days; put the unproven submit/business controls behind an explicit operator stop.
- Automatic mail scans must remain due-filtered; a historical, all-folder scan must be explicitly directory-scoped, read-only, and report selected/skipped/unread counts. Header matches alone do not prove approval.
- Backoff tests should write only a temporary queue and compare unrelated rows byte-equivalently. When a real queue is copied for a dry run, verify future due dates stay unchanged.
- Adding a page-focus guard requires updating legacy fake browser pages in the existing suite. Run every existing suite, golden, leak and runs checks; don't trust only the new regression.
